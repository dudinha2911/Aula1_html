Tag: header

A tag hearder serve para criar o cabeçalho de uma página web ou de uma seção específica

Tag: main

A tag main define o conteúdo principal e único de uma página web

Tag: nav

A tag nav epresenta uma seção de uma página que aponta para outras páginas ou para outras áreas da página, ou seja, uma seção com links de navegação.

Tag: section

A tag section define uma seção temáfica e lógica de conteúdo em uma documento HTML

Tag: article

A tag article no HTML define um conteúdo independente, autossuficiente e reutilizável

Tag: aside

A tag aside define uma seção da página com conteúdo secundário ou que tem relação indereta com o texto principal

Tag: figure

A tag figure serve para agrupar um conteúdo visul ou autossuficiente como foto, diagrama, gráficos, etc.

Tag: footer

A tag footer define o rodapé de uma página wed ou de uma seção específica
